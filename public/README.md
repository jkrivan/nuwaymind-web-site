# NuWayMind static website

Static HTML/CSS/JavaScript website package for nuwaymind.com.

## Files

- `index.html` — page structure and business-focused copy
- `styles.css` — NuWayMind orange-schema styling, responsive layout, Satoshi import
- `script.js` — mobile menu, scroll reveal, section highlight, capability filtering and mailto form

## Brand notes

- Font: Satoshi via Fontshare CSS import. No font files are included.
- Primary accent: orange `#ff8b1f`, matched to the orange schema from the NuWayMind brandbook.
- Supporting colours: slate, pale aqua and mist backgrounds, aligned with the brandbook variations.

## How to use

1. Upload all files to the website root directory.
2. Keep `index.html`, `styles.css` and `script.js` in the same folder.
3. Replace the demo mailto form with a production form handler such as HubSpot, Webflow, Netlify Forms, Formspree or your CRM.
4. Replace the inline SVG logo mark with official exported logo assets if needed.
